

# 导出您的容量管理器数据
<a name="exporting-cm-data"></a>

您可以将容量数据从 EC2容量管理器导出到 Amazon S3，以便进行进一步分析、创建自定义报告或与其他 AWS 服务集成。您可以以 CSV 或 Parquet 格式导出数据。在以下部分中，您将找到有关如何导出容量管理器数据的信息。

**注意**  
容量管理器只允许为每个 AWS 账户进行一次数据导出。

**注意**  
在极少数情况下，如果因数据问题需要重新生成数据导出，新文件将覆盖该小时内的现有文件。
