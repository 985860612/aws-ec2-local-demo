

# EC2 容量管理器
<a name="capacity-manager"></a>

Amazon EC2 容量管理器可帮助从一个位置监控、分析并管理您在按需型实例、竞价型实例和容量预留中所使用的容量。容量管理器通过一个统一的控制面板简化容量跟踪工作，该控制面板会聚合您的使用数据，并每小时刷新，同时提供优化机会。

容量管理器专为大型企业及多账户组织设计，能够消除从多个来源手动收集数据的繁琐流程。该工具可为您提供对各个 AWS 区域的深入见解。您可以深入了解详细的容量指标，并立即采取措施来优化您的云资源。

启用 AWS Organizations 集成后，您便可以在单个控制面板上查看并分析整个组织内所有成员账户的容量数据。如果没有 Organizations 集成，容量管理器只能监控启用该集成的单个 AWS 账户内的资源。

**注意**  
您只能为每个账户在一个 AWS 区域中启用容量管理器。
容量管理器中显示的所有费用均为基于已公布的按需定价计算得出的预估费用。这些预估值不包括节省计划或预留实例之类的折扣。您的实际费用可能与这些预估值有所不同。

## 主要功能
<a name="capacity-manager-key-features"></a>
+ **控制面板**：提供关于按需容量预留、按需使用和竞价型实例使用情况的全面概述，包括有助于改善容量状况的关键指标。
+ **跨账户和跨区域聚合**：通过单个控制面板查看组织内所有成员账户的容量使用情况。容量管理器会将分区内所有区域的数据聚合到启用容量管理器的单个区域中，包括标签数据。对于跨账户数据，容量管理器还提供账户名称作为维度。
+ **基于标签的分组和筛选**：激活 Amazon EC2 资源（例如 `environment` 或 `team`）中的标签键，以便在对容量指标进行分组和筛选时用作维度。容量管理器为 EC2 自动扩缩组、EKS 集群名称、EKS Kubernetes 节点池和 Karpenter 节点池提供的标签默认包含在内。有关更多信息，请参阅 [管理受监控的标签键](managing-monitored-tag-keys.md)。
+ **数据导出**：将容量数据以 CSV 或 Parquet 格式导出到 Amazon S3，以便进一步分析和自定义报告。
+ **API**：使用 `GetCapacityManagerMetricData` 和 `GetCapacityManagerMetricDimensions` 以编程方式查询容量指标。
+ **日期选择器**：分析从一小时到 90 天日期范围内的容量数据。
+ **30 多个指标**：使用 30 多个指标跟踪容量预留、按需型实例和竞价型实例的容量。
