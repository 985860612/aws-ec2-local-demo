

# 了解 EC2 实例主机名和域
<a name="understanding-ec2-instance-hostnames-domains"></a>

EC2 实例地址由若干不同的部分组成。以下是一个使用实例私有 IPv4 地址的 EC2 实例地址示例：

```
   IP address         Domain name                   
   ↓--------↓ ↓------------------------↓
ip-10-24-34-0.us-west-2.compute.internal
↑-----------↑   
  Hostname      
↑--------------------------------------↑ 
    Fully qualified domain name (FQDN)
```

其中：
+ **IP 地址**：与实例关联的主网络接口的主 IPv4 地址。
+ **主机名**：具体 EC2 实例的本地名称（由操作系统使用并用作本地网络标识）
+ **域名**：FQDN 中 AWS 提供的部分
+ **完全限定域名（FQDN）**：包含主机名和域名的完整地址。这是用于通过网络访问实例的完整全球唯一标识符。

根据您为实例或该实例所挂载主网络接口选择的主机名类型，主机名和域名格式将与上面的示例不同。本节介绍主机名类型选项。
