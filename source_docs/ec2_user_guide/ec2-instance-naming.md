

# EC2 实例主机名和域
<a name="ec2-instance-naming"></a>

了解 EC2 实例主机名和域对于有效管理和访问 Amazon EC2 实例非常重要。每个 EC2 实例都可以有不同类型的主机名（私有和公有），从而用于不同的用途并遵循特定的命名惯例。

本主题介绍了 EC2 实例主机名的结构、主机名的构造方式，以及可用的不同主机名类型。您将学习如何查看和修改主机名设置，了解何时使用各种类型的主机名，以及了解 AWS 环境中主机名管理的最佳实践。
