

# 启用 EC2 容量管理器
<a name="enable-capacity-manager"></a>

根据您的要求，可以在两个不同的级别上启用容量管理器。您可以为单个 AWS 账户启用它以仅监控该账户内的资源，也可以将其与 AWS Organizations 集成，以便集中查看组织中的所有成员账户。
+ **组织级别：**在单个控制面板上查看并分析整个组织内所有成员账户的容量数据。
+ **账户级别：**监控单个 AWS 账户内的容量使用情况。
