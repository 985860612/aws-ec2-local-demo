

# EC2Launch v2 和 EC2Config 代理的 Windows 服务管理
<a name="launch-agents-service-admin"></a>

如果您以具有管理权限的用户身份登录实例，则您可以像管理任何其他 Windows 服务一样管理 EC2Launch v2 和 EC2Config 启动代理。EC2Launch v1 是一组 PowerShell 脚本，默认情况下通过计划任务进行管理。本节介绍 EC2Launch v2 和 EC2Config 的服务管理。

要将更新的设置应用到您的实例，您可以从 Microsoft 管理控制台（MMC）服务界面停止并重启 EC2Launch v2 代理或 EC2Config 服务启动代理。同样，安装新版本的启动代理时，必须先停止代理，然后在安装完成后重启代理。

**注意**  
您必须以管理员身份打开 MMC 服务界面才能选择这些操作。为此，您可以从上下文菜单中选择**以管理员身份运行**。或者，要使用键盘打开界面，请执行以下步骤：  
使用 `Tab` 键或箭头键从**管理工具**菜单中选择**服务**菜单项。
使用以下键盘组合以管理员身份打开：`Ctrl` \+ `Shift` \+ `Enter`。

以下过程列出了在实例上停止和启动启动代理的步骤。

**停止启动代理**

1. 启动并连接到您的 Windows 实例。

1. 从 Windows 的**开始**菜单选择**管理工具**。

1. 以管理员身份打开**服务**控制台，如本节开头所述。

1. 在服务列表中，选择在您的实例上运行的代理（**EC2Launch** 或 **EC2Config**），然后从**操作**菜单中选择**停止**。或者，您可以使用上下文菜单停止代理。

**重启启动代理**

1. 启动并连接到您的 Windows 实例。

1. 从 Windows 的**开始**菜单选择**管理工具**。

1. 以管理员身份打开**服务**控制台，如本节开头所述。

1. 在服务列表中，选择在您的实例上运行的代理（**EC2Launch** 或 **EC2Config**），然后从**操作**菜单中选择**启动**或**重启**。或者，您可以使用上下文菜单重启代理。

如果您不需要更新配置设置、创建自己的 AMI 或使用 AWS Systems Manager，则可以删除并卸载启动代理。

*Delete*\*  
删除服务会删除它的注册表子项。

*卸载*  
卸载服务会删除与此服务相关的文件、注册表子项和所有快捷方式。

**删除启动代理**

1. 启动并连接到您的 Windows 实例。

1. 启动 Windows 命令提示符窗口。

1. 运行以下命令之一以删除启动代理。
   + 运行以下命令以删除 C2Launch 或 EC2Launch v2：

     ```
     sc delete ec2launch
     ```
   + 运行以下命令以删除 EC2Config 服务：

     ```
     sc delete ec2config
     ```

**卸载启动代理**

1. 启动并连接到您的 Windows 实例。

1. 选择 **Windows 系统**，然后从 Windows 的**开始**菜单中选择**控制面板**。

1. 选择**程序和功能**以打开您的实例上安装的程序列表。

1. 从列表中选择您的启动代理（**Amazon EC2Launch** 或 **EC2ConfigService**），然后从**文件**菜单中选择**卸载**。或者，您可以使用上下文菜单。
**注意**  
您可以在**版本**列中查看安装的启动代理版本。
