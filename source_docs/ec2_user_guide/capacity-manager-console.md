

# 在 AWS 控制台中浏览容量管理器
<a name="capacity-manager-console"></a>

容量管理器控制台被划分为多个选项卡，这些选项卡可提供容量数据的不同视图：
+ **控制面板**：提供关于按需容量预留、按需使用和竞价型实例使用情况的全面概述，包括有助于改善容量状况的关键指标。
+ **使用情况**：概述按需型实例和竞价型实例的实例使用模式。按容量预留分析覆盖范围，并通过灵活的分组和筛选确定优化机会。
+ **预留**：提供对容量预留的利用情况、管理能力以及各账户和各区域的详细预留指标的分析。
+ **竞价型**：监控竞价型使用模式，并提供跨账户和区域的竞价型实例的成本分析。
+ **数据导出**：管理至 Amazon S3 的数据导出配置，包括计划、格式化和模板选择。
+ **设置**：提供服务配置选项，包括组织访问权限、区域设置和受监控标签键管理。您可以激活 Amazon EC2 资源中的标签键，以便在对容量指标进行分组和筛选时将其用作维度。有关更多信息，请参阅 [管理受监控的标签键](managing-monitored-tag-keys.md)。

在“使用情况”和“预留”选项卡中，容量管理器提供分层导航结构，使您能够从全面概述页面深入查看详细的资源信息。了解这种导航模式有助于您高效地分析容量数据，并发现优化机会。

## 导航层次结构
<a name="navigation-hierarchy"></a>

容量管理器对“使用情况”和“预留”使用三级导航结构：

1. **概述页面**：包含聚合指标的高级摘要。

1. **细分页面**：带有筛选和分组选项的详细分析

1. **详细信息页面：**
   + 使用情况详细信息：关于您所选维度组合的信息，它提供了统计数据和时间序列数据，以帮助您了解使用模式。
   + 预留详细信息：有关特定容量预留的信息，包括利用率统计数据、随时间变化的使用模式以及配置详细信息。

**注意**  
竞价型实例采用简化结构，仅包含一个概览页面。

## 查看“使用情况”和“预留”的明细和详细信息
<a name="navigation-page-breakdown"></a>

“使用情况”和“预留”选项卡都遵循相同的三级导航结构，使您能够从概览页面进入细分页面，再到详细信息页面。访问细分页面和详细信息页面的流程是相似的，只是每个标签内的导航链接位置略有不同。

**要访问资源细分页面**

1. 通过以下网址打开 Amazon EC2 控制台：[https://console.aws.amazon.com/ec2/](https://console.aws.amazon.com/ec2/)。

1. 在导航窗格中，选择**容量管理器**。

1. 选择您要分析的资源类型的选项卡：**使用情况**或**预留**。

1. 在**聚合**部分中，找到细分链接：
   + **使用情况**：在**操作**列中，选择**查看明细**。
**注意**  
根据您的屏幕尺寸或所应用的维度数量，您可能需要横向滚动页面才能找到“查看细分”链接。
   + **预留**：在**预留**列中，选择要查看的预留数量（该数字是一个链接）。

**要访问详细信息页面**

1. 在细分页面上，导航到相关部分：
   + **使用情况**：“独特维度组合”部分。
   + **预留**：“预留”部分。

1. 在所选资源的相关部分中，访问详细信息页面。
   + **使用情况**：在“操作列”中，选择**查看详细信息**。
**注意**  
根据您的屏幕尺寸或所应用的维度数量，您可能需要横向滚动页面才能找到“查看详细信息”链接。
   + **预留**：在预留 ID 列中，选择要查看的预留。
