

# 分组和筛选数据
<a name="grouping-filtering-data"></a>

容量管理器会根据您选择的维度和时段聚合您的指标。如果未选择任何维度，则容量管理器将聚合数据，并在时间范围内为每个时间段返回一个数据点。您可以通过添加维度（包括 Amazon EC2 资源中的标签维度）将数据分组为较小的聚合。
+ **分组**：按区域、实例系列、账户 ID 或标签键等维度细分容量数据。您可以按多个维度对指标进行分组，以进一步细分数据。例如，如果您按照区域和可用区进行分组，那么对于有使用量的每个区域和可用区组合，您将获得一个数据点。
+ **筛选**：仅显示所选维度的特定子集。例如，如果您按实例系列进行分组，则将获得您有使用量的所有系列的数据点。但是，如果您还按 p5 进行筛选，则只能看到 p5 实例系列的数据点。您也可以按标签值进行筛选，例如，按 `environment=prod` 筛选，仅查看生产资源。要筛选没有为所选标签设置值的资源，请按空值进行筛选。
+ **公制单位**：按不同单位（例如 vCPU、实例或预估成本）查看结果。例如，按区域分组并按特定实例系列筛选后，可以在使用的 vCPU 总数、运行中的实例数或估计成本之间切换。

## 如何在控制台中对数据进行分组和筛选
<a name="grouping-filtering-process"></a>

**在容量管理器中对数据进行分组和筛选**

1. 通过以下网址打开 Amazon EC2 控制台：[https://console.aws.amazon.com/ec2/](https://console.aws.amazon.com/ec2/)。

1. 在导航窗格中，选择**容量管理器**。

1. 选择您要分析的资源类型的选项卡：**使用情况**、**预留**或**竞价型**。

1. 在**日期筛选条件**部分，选择日期范围、时区和时间间隔。

1. 在**维度筛选条件**部分，从*选择维度*下拉列表中选择一个维度。不同资源类型的维度选项有所不同。有关更多信息，请参阅 [EC2 容量管理器指标](cm-metrics-units.md)。

   要按标签维度分组，请从下拉菜单中选择标签键（例如 `environment`）。只有处于 `activated` 状态的标签键才可用。有关激活标签键的更多信息，请参阅[管理受监控的标签键](managing-monitored-tag-keys.md)。

   您可以添加多个维度（包括多个标签维度）来创建更精细的分组。

1. 要按所选维度进行筛选，请从*按维度筛选*下拉列表中选择筛选条件选项。

   对于标签维度，筛选器会显示数据中存在的标签值。要筛选没有为所选标签设置值的资源，请选择空值选项。

1. 在**聚合**部分，选择一个单位，以按照 vCPU、实例或预估成本查看结果。

**注意**  
当您按标签维度分组时，没有为该标签设置值的资源将包含在一个单独的分组中，其值为空。这样可以确保所有资源（而不仅仅是已标记的资源）都计入总计。
